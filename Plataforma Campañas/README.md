# Plataforma Campañas
Plataforma de administración enfocada en la administración de clientes, bodegas, productos, stocks, documentos mercantiles de compra y venta, campañas y partidas.Ésta plataforma se centra en el negocio despacho de productos mediante campañas, ingresando sus costos y las partidas a dichas campañas, la generación de las partidas permite la programación de rutas por sectores gracias al envío de whatsapp personalizados a cada cliente para su previa confirmación o rechazo de la reserva de cantidades de producto dentro de la partida.La plataforma cuenta con informes que permiten ver las utilidades generadas de cada campaña, gestionar el envío de notificaciones de cobranza y gestionar el ingreso de pagos entre otras características.

#### - Gestión documentos mercantiles:
<p>Módulo que permite el ingreso de documentos mercantiles tales como ordenes de compra, guías de despacho, facturas, notas de crédito y débito, también permite la administración de sus estados de pago. También permite la interacción con el SII mediante el uso de un servicio externo Libre DTE utilizando su API.</p>
